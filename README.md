## Использование
Приложение разделяет товары по категориям, выводит список товаров, складывает товары для подсчета полной стоимости всех товаров на складе, а так же по классам товаров.
Создан родительский класс для класса продуктов, а так же класс миксин, который выводит информацию о том, от какого класса и с какими параметрами был создан объект.
